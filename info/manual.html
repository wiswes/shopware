WisWes Chat Widget — Manual

This plugin embeds the WisWes AI shopping assistant on your Shopware 6 storefront and exposes a bearer-token-protected MCP tool surface so the assistant can operate the cart, search the catalogue, drive checkout, and look up orders on behalf of your shoppers — all backed by your store's live data.

Requirements

  • Shopware 6.5 or 6.6
  • Outbound HTTPS access from your Shopware server to https://app.wiswes.com
  • Inbound HTTPS access from app.wiswes.com to your storefront — the chat backend calls into /wiswes/_mcp/* to drive cart and checkout operations
  • An email address to receive the WisWes account confirmation (the plugin auto-creates a tenant on first install)

Installation

  1. Install the plugin via the Shopware Store (the standard one-click install) or via Composer: 
    composer require wiswes/shopware-mcp
bin/console plugin:refresh
bin/console plugin:install --activate WiswesWidget
bin/console cache:clear
  2. In your Shopware admin: Settings → Plugins → WisWes.
  3. Click the Install with WisWes button. The plugin opens a one-step form (your shop URL is pre-filled, you only need to confirm the admin email).
  4. The plugin reaches out to app.wiswes.com, creates your tenant, and stores the widget token, tenant slug, and tenant secret in your shop's system_config.
  5. Within ~30 seconds the chat bubble appears on every storefront page.
No theme code edits needed. The plugin injects the embed snippet via a kernel subscriber on the storefront's base_body_inner block, the same hook every Shopware theme inherits. If you've heavily customized your theme, double-check that {% block base_body_inner %} is still extended; if not, the widget won't render and you can fall back to manual injection (see "Troubleshooting" below).

Configuration

Open Settings → Plugins → WisWes → Configure:

FieldPurpose
chatAgentBaseUrlWhere the WisWes backend lives. Default https://app.wiswes.com — only change if you self-host.
widgetTokenAuto-populated by Install. Identifies your shop to the chat backend.
tenantSlugAuto-populated. Your shop's WisWes account name.
tenantSecretAuto-populated. Bearer token the chat backend uses to call back into /wiswes/_mcp/*.
injectOnStorefrontToggle the storefront widget on/off without uninstalling.

Manage the assistant

Day-to-day configuration of prompts, intents, conversation flows, FAQs, and analytics happens in the WisWes Dashboard at https://app.wiswes.com. The Shopware admin module's Open WisWes Dashboard button takes you straight there with single-sign-on.

What the plugin exposes to the chat backend

Every endpoint below is protected by the per-tenant bearer token; the chat backend authenticates with Authorization: Bearer <tenantSecret> on every request.

CapabilityTools
Cartcart_info · cart_add · cart_update · cart_remove
Catalogueproduct_filter · product_get · category_list · product_filter_options
Checkoutpayment_methods · shipping_methods · set_address · place_order
Salesorder_info (guest order lookup by order number + email)

Privacy & data handling

  • The plugin sends no shopper data to WisWes on its own. Data only leaves your shop when a shopper opens the chat and asks something — and only the fields needed to answer their own question.
  • Cart and order operations run on your shop's actual cart context. The chat assistant cannot create parallel carts.
  • The order_info tool requires both the order number and the matching email. Either alone returns no data — preventing shoppers from fishing for orders by email or order number.
  • If you uninstall the plugin, the system_config rows are cleared. Your tenant on app.wiswes.com is preserved so a re-install reconnects to the same conversation history.

Troubleshooting

SymptomLikely cause / fix
Chat bubble doesn't appear on the storefront Confirm Show widget on storefront is on. Hard-refresh (Ctrl/Cmd-Shift-R). View page source — window.CHAT_WIDGET_CONFIG should be present. If not, your theme has skipped base_body_inner; manually paste the embed snippet from Settings → Plugins → WisWes into your theme's base.html.twig.
"Could not connect to WisWes" on Install Outbound firewall blocking app.wiswes.com. Test from the server: curl -I https://app.wiswes.com/api/widget/install-info.
Chat answers about your catalogue are wrong / missing Open the WisWes Dashboard → Tools → click Sync from MCP. The dashboard re-reads your shop's tool list and refreshes the cache.
Want to disconnect Settings → Plugins → WisWes → Disconnect clears the local config but preserves your tenant on app.wiswes.com.
